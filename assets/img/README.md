# Image assets

The site ships image-free (inline SVG/CSS) so it works fully offline. Drop real
assets here and wire them up as noted below.

| File              | Used by                          | Recommended size | Notes                                              |
|-------------------|----------------------------------|------------------|----------------------------------------------------|
| `hero.jpg`        | Hero visual (`.hero__visual`)    | 1080×1600 (tall) | Replace the inline SVG phone mockup in `index.html`. UAE skyline / abaya + phone vibe. Add descriptive `alt`. |
| `og-image.png`    | Open Graph + Twitter share card  | 1200×630         | Already referenced in `<head>` meta tags.          |

See the root `README.md` → "Where to swap images" for the exact markup.
